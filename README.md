# Auth Service

## Descrição

Microservice de autenticação e autorização para aplicações web e mobile, fornecendo suporte a diferentes métodos de autenticação e gerenciamento de permissões.

## Funcionalidades

- Spring Framework
- **Spring Boot**
  - Automatic Run, Configurations and Dependencies
  - Embedded Application Server
- **Spring Web**
  - Validation
  - API RESTful
- **Spring Data**
  - **JPA**
    - Pagination
    - Repositories
    - JPA Criteria Builder
    - @Query
    - Filters
- Spring AMQP
- **Spring Security**
  - **Authentication**
    - Basic Authentication
    - Token Authentication
      - JWT
      - Encrypted Token
      - Opaque Token
      - Refresh Token
  - **Authorization**
    - Roles
    - Permissions

## Pré-requisitos

- Java Development Kit (JDK) 21 ou mais recente
- Maven
- Docker
- Postman
